Visual Gantt Help Guide

Getting Started

  1. Setup Data Sheet: Click Visual Gantt > Setup Data Sheet to create the project data template.
  2. Add Tasks: Fill in your project tasks in the data sheet with required information.
  3. Generate Timeline: Click Visual Gantt > Generate Timeline to create your Gantt chart.
Quick Start: Use Visual Gantt > Create Sample Data to see an example project with realistic data.

Configuration Options

Access settings via Visual Gantt > Configure Settings:

  • Date Range: Set custom start/end dates or auto-calculate from tasks
  • Swimlane Grouping: Group tasks by Category, Owner, or None
  • Color Scheme: Color bars by Priority, Task Type, or Swimlane
  • Display Options: Toggle dependencies, progress bars, milestones, and today marker
  • Layout: Adjust bar height, spacing, chart dimensions, and font size

Working with Dependencies

Dependencies show which tasks must complete before others can start:

  • Enter dependency Task IDs in the Dependencies column
  • Separate multiple dependencies with commas (e.g., MECH-001, ELEC-002)
  • Dependencies are shown as arrows connecting tasks

Dependency Types:

  • FS (Finish-to-Start): Default. Successor starts after predecessor finishes.
  • SS (Start-to-Start): Both tasks can start together.
  • FF (Finish-to-Finish): Both tasks finish together.
  • SF (Start-to-Finish): Predecessor start triggers successor finish.

Lag/Lead Time:

  • Positive value = Lag (delay). Task B starts 3 days AFTER Task A finishes.
  • Negative value = Lead (overlap). Task B starts 2 days BEFORE Task A finishes.
Note: Circular dependencies (A depends on B, B depends on A) will be detected and reported as errors.

Critical Path

The critical path identifies tasks that directly impact the project end date:

  • Access via Scheduling > Calculate Critical Path
  • Critical path tasks are highlighted in red
  • Any delay on these tasks will delay the entire project
  • Use Views & Filters > Critical Path Only to focus on critical tasks

Baseline Tracking

Track schedule changes against your original plan:

  • Save Baseline: Baseline > Save Current as Baseline to capture current dates
  • Compare: Baseline > Compare to Baseline to see schedule slippage
  • Baseline bars appear below task bars in the timeline when enabled
  • Red highlighting shows tasks that have slipped past their baseline

Auto-Scheduling

Automatically cascade date changes through dependencies:

  • Access via Scheduling > Auto-Schedule Tasks
  • Tasks are scheduled as early as possible based on predecessors
  • Respects dependency types (FS, SS, FF, SF) and lag/lead times
  • Considers work days when "Exclude Weekends" is enabled
Tip: Save a baseline before auto-scheduling to track changes!

Filters & Views

Quickly focus on specific tasks via Views & Filters:

  • My Tasks: Show only tasks assigned to you
  • Overdue Tasks: Tasks past their end date that aren't complete
  • At Risk Tasks: Tasks with "At Risk" status or Yellow/Red health
  • Critical Path Only: Focus on schedule-critical tasks
  • Show All: Remove filters and show all tasks

Cost Tracking

Track budget vs actual costs:

  • Enter planned costs in "Budget Cost" column
  • Update "Actual Cost" as work progresses
  • View cost summary via Views & Filters > Cost Summary View
  • Parent task costs automatically roll up from children

Holiday Management

Exclude holidays from work day calculations:

  • Access via Manage Holidays
  • Add company holidays that should be excluded from scheduling
  • Works with "Exclude Weekends" setting for accurate date calculations

Milestones

Milestones are key project events shown as diamond markers:

  • Set Task Type to "Milestone"
  • Milestones only need a Start Date (End Date will be set automatically)
  • Use milestones for reviews, deadlines, and deliverables

Export Options

  • Save to Sheet: Click "Save to Sheet" in the timeline view to embed the chart in your spreadsheet
  • Export as PNG: Download a high-quality image for presentations
  • Export as PDF: Create a PDF document for printing or email

Tips for Best Results

  • Use consistent naming conventions for Task IDs
  • Group related tasks with the same Swimlane/Category
  • Keep task names concise (they may be truncated in the timeline)
  • Update % Complete regularly to track progress
  • For large projects (100+ tasks), increase chart dimensions in settings
